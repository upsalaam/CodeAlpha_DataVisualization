E-commerce Sales Data Analysis & Visualization

Project Overview

This project analyzes e-commerce sales data using Python. It explores sales performance across regions and products and identifies monthly sales trends through data visualization.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- VS Code

Dataset

The dataset contains the following columns:

- Order Date
- Product Name
- Sales
- Quantity
- Region

Data Inspection & Cleaning

The project uses Pandas to inspect and check the dataset with:

- "head()" and "tail()"
- "shape", "info()", and "describe()"
- "isnull()" and "dropna()"
- "duplicated()"

The missing-value and duplicate-row checks returned zero for the dataset examined.

Visualizations

Four charts were created:

1. Total Sales by Region
2. Monthly Sales Trend
3. Sales by Product
4. Quantity by Region

Key Business Insights

- The East region recorded the highest total sales among regions.
- The North region recorded the lowest total sales among regions.
- Camera ranked first by total sales, followed by Monitor and Printer.

Project Files

- "Pandas.py" — data inspection and analysis
- "Matplotlib.py" — data visualizations
- "ecommerce_sales_data.csv" — dataset

How to Run

1. Install Python.
2. Install the required libraries:
   "pip install pandas matplotlib"
3. Open the project folder in VS Code.
4. Run the Python scripts.
